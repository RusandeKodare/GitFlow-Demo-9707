This project was created with a PowerShell script that demonstrates GitFlow-style collaboration using Git and GitHub. It automates the creation of a GitHub repository, simulates collaboration between two developers (Me and MyFriend), and showcases key GitFlow concepts such as feature branching, rebasing, resolving merge conflicts, and creating pull requests. It aims to help developers understand and practice GitFlow workflows in a controlled environment

The script was designed by [Benjamin Österlund](https://github.com/benjaminosterlund).
